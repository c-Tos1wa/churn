# Projeto Análise de dados para determinar como resolver problema de churn

## Objetivo

Uma empresa percebeu que, do total da sua base de dados, a maioria dos clientes já cancelaram o serviço. Visando melhorar seus resultados,
um analista de dados deve conseguir entender os principais motivos de desistência e quais ações serão necessárias para reduzir esse número.

## Pré-requisitos

```
python 3
poetry
pyenv
```

## Como iniciar este projeto 

- Pelo terminal, clonar o projeto usando:
  
```
git clone git@github.com:c-Tos1wa/churn
```

- dentro da pasta criada
  
```
poetry install
```

- ativar o ambiente usando:
  
```
eval $(poetry env acitvate)
poetry run jupyter-lab
```
